# calc-rule：规则引擎

## 职责边界

把「规则集」变成可执行的期级决策：表达式解析求值、规则编译与编译期校验、函数库、
函数脚本装载、以及实现 domain 端口的规则驱动生成器。只依赖 calc-common 与 calc-domain。

## 流水线（单向，不可跳段）

1. **词法/语法**：表达式 → 语法树；语法与嵌套深度在解析期拒绝。
2. **编译**：规则行 → 编译规则集；编译期校验（区间、计划总量、利率范围、动作与利息
   处理方式白名单）在进入生成器之前完成——**错误的规则集不得到达运行时**。
3. **求值**：期级变量白名单构成求值上下文；行条件与区间在解析期判定。
4. **运行**：规则驱动生成器逐期解析；未覆盖期是**阻断错误**，除非选项显式允许回落——
   回落必须带类型化标记并披露为 WARN，不由调用方从字符串反推。

## 依赖倒置

`RuleSetView` 端口（只读、按期解析）定义在 calc-domain，本模块是实现方——
因此内置算法可消费规则而不依赖规则模块。**端口语义改动在 calc-domain 裁定**，
本模块跟随。

## 函数注册表

公式函数（金融/日期/逻辑/数学/查找/文本/信息）是规则的求值底座，注册表**单源**：
运行时求值、规则编译与函数脚本共用同一实例——两个注册表分叉是禁止态。
函数脚本（`.fcs`）定义可覆盖与扩展，但禁止递归、有节点预算、解析失败即失败——
装载路径**快速失败，不降级**。

## 纪律

- 每条拒绝路径都有自己的 FCS-RULE 码（码随路径进入，不借用别义码）。
- 表达式与脚本是**输入**，不是程序：求值环境封闭，白名单之外一概未知。
- 规则驱动生成器的每次运行状态（池、摊铺区间）收敛在每次运行的计划视图里，
  不落在可共享的实例上；回落期次的披露在生成器内完成。
- 数值精度与回落语义的硬约束以 `AGENTS.md` §1、§3 为准。
