# calc-common：共享原语

## 职责边界

只承载被所有模块复用的**无业务语义原语**：金额精度与容错、日期时间提供者、错误码骨架、
扩展点注册表。它只依赖 JDK，是依赖图的根。

## 对外接口（不变）

- **金额**：精度常量、舍入模式、比较容差的**单一出处**——任何模块不得自定容差字面量，
  生成器与校验器必须在同一条线上判定。
- **时间**：时钟提供者接口 + 系统实现（可注入、可替换）。
- **错误码**：业务异常（含 FCS 码与消息模板）与系统异常两类；错误码按模块分段命名
  （见 calc-server 的码表），本模块只定义骨架。
- **扩展点注册表**：泛型注册表，按 code 注册与查找；同 code 后注册覆盖先注册；
  有序扩展按 order 排序（同序按注册序）；也支持服务发现装载。

## 纪律

- 本模块**只进不出语义**：不 import 任何兄弟模块，不写任何测算逻辑。
- 新增原语前先问：它是否被 ≥ 2 个模块需要？只被一个模块需要的逻辑留在那个模块。
- 注册表是深模块：一个接口承载全部扩展点生态；改它的契约要过全模块测试。
