# fincalc-engine：测算引擎架构（唯一对外技能）

> 引入规则：本技能是测算引擎**唯一的对外技能**。先读本文件建立全局图景，再按所改模块
> 加载 `references/` 下对应的分模块文档。硬约束源是仓库根 `AGENTS.md`；本技能只描述
> 结构，不复制数字——阈值、精度位数、上限一律以 AGENTS.md 与代码常量为准。

## 模块地图与依赖方向（全引擎）

```
消费者（HTTP 等，不在技能范围）
        │ 仅经由唯一入口
        ▼
calc-engine ──► calc-rule（实现 domain 的端口）
      │               │
      ▼               ▼
calc-domain ──► calc-common（仅 JDK）
```

依赖箭头单向无环；`RuleSetView` 端口定义在 calc-domain、实现在 calc-rule，
是全引擎唯一的依赖倒置锚点。

## 编排流程（不可变顺序，每步消费上一步产物）

入口校验 → 上下文装配（口径 code 必须命中注册表）→ 路由生成原始摊销表 → 现金流事件表 →
指标运行 → 校验链与引擎诊断 → 实际利率表（失败答 null + WARN，永不抛出）→ 结果（runId）。
步骤明细、装配契约与失败语义见 `references/calc-engine.md`。

## 全局不变量

- **精度纪律**：内部精度、求根轮次与容差、先明细求和再舍入——一律以 `AGENTS.md` §1 为准。
- **一次一解**：同一流不重复求根；第二次求解必须写明口径差别（见 `references/calc-engine.md`）。
- **失败语义**：可计算性失败是「显式 null + WARN」，不是 0；校验 ERROR 不得降级放行。
- **数值逐位一致**：日志、重构、性能优化均不得改变任何输出金额与率值。
- **产品盲内核**：产品身份只在编排层选择校验链，内核不感知产品。
- **方向表达**：金额字段恒非负，收付方向由方向字段表达。

## 扩展缝（全部经注册表）

生成器 / 指标 / 校验器 / 口径约定（计息基准、日期调整）/ 尾差策略 / 现金流构建器 /
公式函数，均经统一扩展点注册表按 code 注册与路由；同 code 后注册覆盖先注册。
新增扩展点前先回答：**它改变哪一期现金流或余额？** 答不出即不是测算要素。

## 改动完成检查

全模块测试（含 §6 性能闸门）+ 依赖方向守卫；命令与工程事实见 `AGENTS.md` §7。
