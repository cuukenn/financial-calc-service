# 12. 抵押物类型 / 房龄 / 城市首付下限

Status: needs-triage
Type: task
Priority: P3
数据角色: C 政策提示 —— 不参与测算，不影响任何现金流
Blocked by: —

## 背景

全国首付下限已统一为 15%（2024-09 通知），但地方可更高；另外抵押物类型与房龄会影响评估
与贷款成数的实务上限。当前表单没有这些维度，只能按全国下限判，地方政策无法表达。

## 要做什么

1. 新增：抵押物类型（住宅 / 商用 / 其他）、房龄（年）、所在城市（可选）。
2. 城市可维护一个下限配置（默认 15%），命中城市时用该城市下限并**明确展示依据**。
3. 房龄只做提示（不阻断），避免把商业规则写死进代码。

## 验收标准

- 未选城市时回落到 15%，文案说明「按全国统一下限」。
- 选中配置了更高下限的城市时，闸门使用该值，且拦截文案写明来源。
- 房龄只影响提示，不影响提交。

## 涉及文件

`web/src/components/MortgageForm.vue`、`web/src/i18n/locales/*.ts`、
`web/src/utils/ratio.ts`（下限常量的来源收敛）。
