# 04. 费用：承担方与含税/不含税口径

Status: needs-triage
Type: task
Priority: P2
数据角色: A 参与测算 —— 费用承担方决定现金流方向，含税口径决定税额
Blocked by: —

## 背景

`AGENTS.md` §3.1 第 12 条要求「费用与税（含税/不含税、差额征税、费用承担方）」显式提供。
现状的费用行只有「类型 + 金额 + 收取方式（期初一次性 / 抵减本金 / 摊入租金）」，说不出
这笔费用由谁承担、金额是含税还是不含税 —— 而出租人与承租人承担的费用对 IRR 的影响相反。

## 要做什么

1. 费用行新增 `承担方`（出租人 / 承租人）与 `含税口径`（含税 / 不含税）。
2. 含税费用参与税额反算时按 §1 P-12 的价税分离规则（销售额与税额各 2 位）。
3. 差额征税项目单独列示扣除额（§4 增值税口径）。

## 验收标准

- 同一笔费用换承担方后，出租方 IRR 与承租人视角指标按方向变化，且金额守恒。
- 含税/不含税两种录入在税额上互相可复算（误差 ≤ 0.01 元，超出即报校验问题）。

`web/src/components/FeesEditor.vue`、`web/src/i18n/locales/*.ts`、
