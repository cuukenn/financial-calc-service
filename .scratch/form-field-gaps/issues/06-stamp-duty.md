# 06. 印花税测算（租金总额 0.005%）

Status: ready-for-agent
Type: task
Priority: P2
数据角色: B 结果派生 —— Σ租金（不含税）× 0.005%，不进现金流
Blocked by: —

## 背景

`AGENTS.md` §4：融资租赁合同是《印花税法》（2022-07-01 施行）的独立税目，税率为租金总额的
**0.005%**（万分之零点五，不含单列增值税）。当前 UI 完全不含印花税，报价单里这一项只能手工
加。这是纯前端可做的增量，**不需要改引擎契约**。

## 要做什么

1. 结果区新增「印花税」一行：`计税依据 = Σ 租金（不含增值税）`，税额 = 依据 × 0.005%。
2. 显示计税依据与税率，便于对账；税额按 P-05 输出 2 位小数。
3. 明确标注这是**合同税费**，不进摊销表、不进 IRR 现金流（避免与租金口径混淆）。

## 验收标准

- 用租赁黄金基线（TOTAL_RENT 1,032,797.15）算出的印花税与手算一致（0.01 元容差内）。
- 含增值税场景下计税依据不含税额。
- 文案明确「不进 IRR」，并在 README/结果区同口径。
