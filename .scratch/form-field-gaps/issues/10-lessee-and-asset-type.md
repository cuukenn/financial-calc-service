# 10. 承租人 / 关联方 / 租赁物类型（集中度与 VAT 档位）

Status: wontfix
Type: task
Priority: —（D 档，本产品不做）
数据角色: D 报表层 —— 需要存量余额与净资产，本计算器不产出
Blocked by: 01

## 背景

`AGENTS.md` §2.3 的监管阈值里，单一承租人、单一集团客户、单一客户关联度、全部关联度都
需要**承租人身份**才能计算；§4 的增值税档位（有形动产 13% / 不动产 9%）取决于**租赁物类型**，
现在 VAT 率靠手填，容易填错档。这些字段不进现金流，但决定报表与合规结论。

## 结论（2026-11-11 裁定）

集中度 / 关联度需要「净资产」与「存量融资余额」这类**外部账本**数据，不属于一次测算的
输入或输出；把它们塞进计算器就是「为算指标而算指标」。本 issue 转 wontfix，交报表 / 租赁
资产管理系统。

仅保留一个纯前端的小点：租赁物类型（有形动产 / 不动产）决定增值税档位 13% / 9%，这个
**参与测算**，已由 04 覆盖；若需要联动可并入 04，不单独开工。

## 原方案（不执行）

1. 新增：承租人标识（名称或编号）、是否关联方、所属集团（可选）。
2. 新增：租赁物类型（有形动产 / 不动产），选择后自动带出建议 VAT 率（可覆盖但要留痕）。
3. 结果区增加「集中度」区块：单一承租人融资余额 / 净资产、单一集团 / 净资产、
   关联度 / 净资产，按 §2.3 阈值着色（未填净资产时显示不可判定，不显示 0）。

## 验收标准

- 承租人缺省时集中度区块整体隐藏，不显示 0 或「合规」。
- 租赁物类型切换后 VAT 默认值正确，手填值与默认值不同时在备注列标明。
- 阈值比较用未舍入原值（P-10），恰好等于阈值时判合规（含本数）。
