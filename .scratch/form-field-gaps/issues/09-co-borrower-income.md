# 09. 房贷共同申请人 / 配偶收入与债务

Status: needs-triage
Type: task
Priority: P3（C 档读数，不参与测算）
数据角色: C 监管读数 —— 不参与测算，DTI 由结果月供与收入派生
Blocked by: —

## 背景

`AGENTS.md` §2.2：单一申请人用本人可支配收入；**含配偶收入时须一并计入配偶债务**；共同申请
用主申请人 + 共同申请人可支配收入并计入其全部债务。现状只有「月可支配收入」与「其他月债务
支出」两个槽位，多申请人只能人工合并，最容易出的错就是「加了配偶收入、没加配偶债务」。

## 说明

按 2026-11-11 裁定的指标口径原则，本项属于 C 档监管读数：它不进入现金流与摊销表，
不应当被当成「核心指标」。保留它只因为 DTI 是放款前的合规判定，且 §2.2 明确要求配偶收入
与配偶债务同时计入。**不得**为它新增任何影响测算的字段。

## 要做什么

1. 「收入与债务」改为可增删的申请人列表：每个申请人有「月可支配收入」与「其他月债务支出」，
   首行为主申请人。
2. DTI 与月所有债务支出/收入比按**合计**计算，并在读数旁标注「含 N 位申请人」。
3. 任一申请人的债务未填而收入已填时给出提醒（不阻断，避免误拦）。

## 验收标准

- 两位申请人时，DTI = 月供 ÷（两人收入之和）；全部债务比 =（月供 + 两人债务）÷ 收入之和。
- 单申请人时与现状逐位一致。
- 未舍入原值判限（P-10）在合并后依然成立。
