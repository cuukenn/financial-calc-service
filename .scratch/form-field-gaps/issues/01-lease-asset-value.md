# 01. 融资租赁补「租赁物价值」与首付款

Status: resolved（2026-11-11 按标准计量链落地）
Type: task
Priority: P1
数据角色: A 参与测算 —— 改变租赁内含利率的分母与首付款
Blocked by: —

## 背景

`AGENTS.md` §3.5 的融资租赁最小要素集第一项就是**租赁物价值**，但表单里只有「租赁本金」。
两者是不同概念，混用会让两件事都算不对：

- 首付款 = 租赁物价值 − 租赁本金；
- 租赁内含利率的定义（§2.1、CAS 21）是「租赁收款额现值 + 未担保余值现值 = 租赁资产
  公允价值 + 出租人初始直接费用」——分母不是本金。

## 要做什么

1. 表单「租赁要素」新增 `资产价值`（租赁物价值）字段；本金仍单独录入。
2. 前端派生并展示 `首付款 = 价值 − 本金`，本金大于价值时给出校验错误（不得静默为负）。
3. 引擎侧新增可选输入 `assetValue`（缺省时退回当前「本金 = 价值」的既有口径，保证旧请求
   行为不变），用于租赁内含利率与首付款计算。
4. 结果区标注本次测算用的是哪一种口径。

## 实测发现（2026-11-11）—— 实现已撤回

先按「assetValue 的真消费者是内含利率」做了一个 `LEASE_IMPLICIT_RATE`：把期初流出替换为
资产价值后求解 IRR。真机一把就否掉了这个口径：

```
principal=1,000,000  assetValue=1,200,000  →  LEASE_IMPLICIT_RATE = -23.77%
```

原因不是算错，而是**模型缺了首付款**：rents 是按本金（融资额）算的，PV(租金) = 本金；
若分母换成资产价值而不把「首付款 = 价值 − 本金」作为 t0 流入加回来，贴现率只能为负。
而一旦把首付款加回来，t0 净额又回到 −本金，内含利率与 `IRR_ANNUAL` **逐位相等** ——
多出来的指标也就没有存在价值（正是 M-01/M-02 要防的「为算指标而算指标」）。

结论：**这个字段不是缺一个输入框，而是缺一个领域决策**。必须先定：

1. 首付款是否作为 t0 真实现金流显式建模（进现金流表、进 IRR）？
2. 若进，内含利率是否还有独立定义（CAS 21 的「资产价值 + 初始直接费用」分母 vs 本金的区别）？
3. 租金究竟按「本金」还是按「资产价值」生成？

在 1–3 有答案之前，`assetValue` 不应进入契约。本轮代码已全部撤回，`AGENTS.md §5` 与
「留购价」改名（issue 11）保留。

## 验收标准

- 只填本金时，全部既有测试与黄金基线不变（向后兼容）。
- 同时填价值与本金时，首付款在 UI 可见，且租赁内含利率的分母使用「价值 + 初始直接费用」。
- 本金 > 价值时提交被拦，提示文案说明原因。

## 落地记录（2026-11-11）

三个领域决策由 `docs/superpowers/specs/2026-11-11-lease-measurement-standard.md` 回答后完成：

- 计量链：`资产价值 + IDC = PV(租赁收款额) + PV(未担保余值)`，`融资额 = 价值 + IDC − 首付`；
  租金按**融资额**生成（不是按资产价值）。
- 首付款是 `租赁收款额` 的一项，作为 t0 收款进入现金流（不是利息的减项）。
- 内含利率只在 IDC 或未担保余值 > 0 时才与 `IRR_ANNUAL` 分离；否则两者恒等，UI 已注明。

实现落点：

| 层 | 内容 |
|---|---|
| 领域 | `LeaseElement.assetValue / downPayment / initialDirectCosts / guaranteedResidual / unguaranteedResidual`，恒等式 `FCS-DOM-1016`（容差 `MoneyTolerance.MONEY_COMPARE`） |
| 契约 | `CalculationRequestDto` + `CalculationRequestAssembler` 五字段，缺省不发送 |
| 表单 | 资产价值 + 首付款 + IDC + 两项余值；实时派生「融资额」并在提交时替换 `principal` |
| 现金流 | t0 流出 = 资产价值 + IDC；首付款 t0 流入；担保余值期末流入；未担保余值不进现金流 |
| 指标 | `LEASE_IMPLICIT_RATE`（第 26 个 code），分母 = 资产价值 + IDC |

真机校验：`principal=2010000 / 价值 2400000 + IDC 10000 − 首付 400000` → 200；
`principal=1900000` → 400 `FCS-DOM-1016`。

残余项：担保余值目前只影响现金流、不影响摊销表（与「留购价单独支付」一致）；若要变成气球
式，应复用 `residualHandling` 而不是新增字段。
