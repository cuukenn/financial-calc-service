# 表单字段差距（融资租赁 / 房贷计算器）

2026-11-11 对两个表单做了一次「实际业务需要录入什么」的核对，结论：**两个表都能把
「一次测算」算对，但都不是「一笔业务的录入界面」。**

## 指标口径原则（2026-11-11，用户裁定）

> 不能为了算指标而算指标；核心指标应该是**参与测算的数据本身**，以及**结果带出来的**量。

据此把字段与指标分四类，越靠前越是核心：

| 层级 | 定义 | 处理 |
|---|---|---|
| **A 参与测算** | 进入现金流 / 摊销表的输入：改一个数，结果就必须变 | 核心，优先补 |
| **B 结果派生** | 由 A 与摊销表直接推出的量（租金、利息、IRR/XIRR、EIR、余额、结清额、印花税） | 核心，随结果一起给出 |
| **C 监管读数** | DTI、LTV、首付比例的合规判定 | 可展示，但**不为它引入不参与测算的字段**，也不得让读数看起来像测算结果 |
| **D 报表层** | 集中度、关联度等需要存量余额与净资产的指标 | 不属于本计算器，交报表 / 资产系统 |

推论：C 类字段（如共同申请人、城市首付下限）不是核心要素，最多是仪表输入；D 类
（承租人关联度、集中度）不出现在本产品里。

## 现状盘点

### 融资租赁（`web/src/components/CalculationForm.vue`）

- **租赁要素**：租赁本金、名义年利率、起租日、首期租金支付日、期数、币种、支付频率、
  支付时点、计息基准、日期调整、利率变更策略、还款方式（等额本息 / 等额本金 / 先息后本 /
  先本后息 / 到期一次还本付息 / 规则驱动 / 显式租金）
- **租金结构**：规则行（分段利率，可选）、逐期租金（显式租金时）、宽限期（只付息期数 /
  全免期数）
- **费用与其他**：费用列表（类型 + 金额 + 收取方式）、残值 / 留购价、残值处理、保证金、
  增值税率

### 房贷（`web/src/components/MortgageForm.vue` + `MortgageIncomePanel.vue`）

- **贷款要素**：贷款金额、贷款期限（月）、当前 LPR（%）、加点（bp）、合成年利率（只读）、
  放款日、首期还款日、还款方式（等额本息 / 等额本金 / 到期一次还本付息，后者仅 ≤ 12 期）
- **抵押物与杠杆**（C 类读数）：成交价、评估价 → 抵押物价值、LTV、首付比例
- **收入与债务**（C 类读数）：月可支配收入、其他月债务支出 → 月供、两条 DTI

## 非目标

- 不为「展示得更全」而新增不参与测算的字段（用户 2026-11-11 裁定）。
- 不在本轮改动引擎契约或指标口径（Plan 5 已冻结）。
- 不引入客户 / 合同主数据管理，只到「录入够算这一笔」的粒度。
