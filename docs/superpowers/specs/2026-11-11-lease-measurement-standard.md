# 租赁计量口径（CAS 21 / IFRS 16）—— 引擎标准化目标

2026-11-11 用户目标：引擎按**国际/国家标准**建模，不按 UI 方便建模。
本文件钉住计量链，作为 issue 01/03/04/05 的共同前提。

## 1. 依据

- CAS 21（2018 修订）第十六、十七、十八、三十七、三十八条
- IFRS 16 §26–§28、§38（租赁内含利率 / 增量借款利率）
- AGENTS.md §2.1、§2.4、§3.4

## 2. 计量链（出租人）

资产价值（公允价值）+ 初始直接费用（IDC）= 租赁投资净额（起租日）
= PV(租赁收款额) + PV(未担保余值)

租赁收款额 = 首付款（起租日或之前支付）+ 各期租金（固定/实质固定，扣租赁激励）
+ 取决于指数或比率的可变付款额 + 留购价（合理确定将行使）+ 担保余值

内含利率 = 使上式成立的折现率，且是**定价输入**：先定目标收益率，再由
「融资额 = 资产价值 + IDC − 首付款」生成租金。

## 3. 关键结论

| 情形 | 内含利率与 IRR 的关系 |
|---|---|
| 无 IDC、无未担保余值、租金按融资额 | 恒等（同一根） |
| 有 IDC | 内含利率 < IRR（分母更大） |
| 有未担保余值 | 内含利率 < IRR（左侧多一项非现金现值） |
| 有担保余值 | 计入收款额，仍同根 |

UI 必须写明，否则用户会以为是两个独立指标。


## 4. 引擎改动（按依赖顺序）

1. **A 类输入**：`assetValue`（公允价值）、`downPaymentRatio` 或直接 `downPayment`、
   `initialDirectCosts`、`guaranteedResidual`、`unguaranteedResidual`。
2. **派生**：`principal = assetValue + IDC − downPayment`（引擎侧校验，前端只展示）。
3. **校验（§3.4 扩展）**：
   - Σ本金 = principal（不含首付款，首付款不是融资额）；
   - 末期余额 = 并入租金的留购价；
   - Σ租金 + 首付款 + 留购价 = 本金 + 利息 + 费用 + 税 + IDC（按口径拆分）。
4. **指标**：`LEASE_IMPLICIT_RATE` 只在 IDC 或未担保余值 > 0 时与 `IRR_ANNUAL` 分离；
   否则返回与 IRR 相同的值并在 UI 标注「恒等」。
5. **现金流**：首付款是 t0 INFLOW；IDC 是 t0 OUTFLOW；未担保余值不是现金流，
   只进入内含利率方程。

## 5. 与现有实现的差异

- 现有 `residualValue` 实为**留购价**（已按 issue 11 改名）；
- 现有引擎不含 IDC、担保余值、未担保余值；
- 现有租金按 `principal` 生成，尚无「价值 → 首付 → 融资额」链。
